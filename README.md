## Features

- Interactive 3D rotation and zoom controls
- Color variants customizer
- Interactive hotspots with detail popups
- Auto-rotation mode
- Clean modern UI built with Tailwind CSS

## Tech Stack

- **Framework:** React 19
- **Bundler:** Vite
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript
